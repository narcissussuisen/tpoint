# T点监控 v9 设计文档

> 状态：开发中 · 基于 v8 重构 · 直击两大生产缺陷
> 日期：2026-07-07

## 一、设计目标

v8 在生产环境暴露两大致命缺陷，v9 必须根治：

| 缺陷 | v8 现象 | 根因 |
|------|---------|------|
| S 信号在下跌趋势几乎不触发 | 7/3 全天 25 个 B、0 个 S | S 条件需"价格先站上阻力2根再回落"，而阻力随价格单边下移，下跌时价格根本没站上过阻力 |
| B 信号频繁误发 | 震荡日单标的 10+ 信号 | 仅 LONGCROSS(支撑,C,2)，无趋势/量价过滤 |

附带问题：支撑阻力用 `np.maximum.accumulate(当日最高价)` 动态计算，下跌时整体下移，失去"价值锚"意义。

## 二、核心范式转变

```
v8: 价格穿越「静态支撑阻力线」        → 信号
v9: 价格对「VWAP价值中枢」的偏离
    × 趋势状态 × 量价共振 × 情绪温度  → 信号
```

**关键原则**：信号方向与趋势同向。下跌趋势主动发 S（反弹至 VWAP 遇阻），上升趋势主动发 B（回踩 VWAP 获支撑）。无论涨跌都有可交易信号，不再依赖"价格站上阻力"这种下跌时永不成立的条件。

## 三、五大模块

### 模块 1：VWAP 价值中枢（替代 v8 支撑阻力）

- 日内累计 VWAP = `cumsum(typical_price × volume) / cumsum(volume)`
- typical_price = (high + low + close) / 3
- 性质：**日内水平线，不随价格单边下移** → 直接解决缺陷 2
- 价格 > VWAP = 多头区域；< VWAP = 空头区域
- **容错**：若 intraday 数据无 volume 字段，退化为 `cumsum(close)/count`（等权均价），仍优于 v8 的下移支撑

### 模块 2：ATR 波动带

- ATR(14) 衡量正常波动幅度
- 标准轨：`VWAP ± k1 × ATR`（k1=1.0，趋势跟随触发区）
- 极端轨：`VWAP ± k2 × ATR`（k2=2.0，均值回归触发区）
- 触及极端轨且反转 = 高胜率信号（统计上 2σ 外回归概率 > 80%）

### 模块 3：趋势过滤

三态判定：
- **上升趋势**：EMA20 > EMA60 且 ADX(14) > 20
- **下降趋势**：EMA20 < EMA60 且 ADX(14) > 20
- **震荡**：ADX(14) ≤ 20

信号门控：
- 上升趋势 → 只发 B（回踩买），S 降级为观察
- 下降趋势 → 只发 S（反弹卖），B 降级为观察 ← **核心改进，解决缺陷 1**
- 震荡 → 双向发，用极端轨 + 均值回归逻辑

### 模块 4：量价确认

- 量比 = 当前 bar 成交量 / 过去 20 bar 均量
- B 信号需：量比 > 1.2 且收阳（close > open）→ 放量阳线确认
- S 信号需：量比 > 1.2 且收阴（close < open）→ 放量阴线确认
- 量价背离（价涨量缩 / 价跌量缩）的信号降级处理
- **容错**：无 volume 时跳过此门控，仅靠价格反转 + 趋势

### 模块 5：情绪温度计

归一化到 0-100 的综合情绪指标：

| 子项 | 权重 | 计算方式 |
|------|:---:|----------|
| RSI(14) | 0.4 | 直接取 RSI 值 |
| 当日涨跌幅 | 0.2 | 映射 [-5%, +5%] → [0, 100] |
| 量比偏离 | 0.2 | 映射 [0, 3.0] → [0, 100] |
| 价格对 VWAP 偏离 | 0.2 | 映射 [-2%, +2%] → [0, 100] |

门控逻辑：
- 温度 > 70（偏热）：S 信号加权增强，B 信号抑制（不追多）
- 温度 < 30（偏冷）：B 信号加权增强，S 信号抑制（不杀跌）
- 30-70 中性：正常

## 四、信号生成逻辑（核心）

### B 信号（做 T 低吸）

触发条件（全部满足）：
1. 趋势状态 ∈ {上升, 震荡}（下降趋势不发 B）
2. 价格触及或跌破标准下轨（VWAP - k1×ATR）
3. 反转确认：当前 bar 收阳且收回下轨上方（或长下影 ≥ 1×ATR）
4. 量价确认：量比 > 1.2 且收阳（无 volume 时跳过）
5. 温度计 < 70（过热不追多）

强度由温度（越冷越强）+ 量比（越大越强）决定星级。

### S 信号（做 T 高抛）

触发条件（全部满足）：
1. 趋势状态 ∈ {下降, 震荡}（上升趋势不发 S）← **核心改进**
2. 价格触及或涨破标准上轨（VWAP + k1×ATR）
3. 反转确认：当前 bar 收阴且收回上轨下方（或长上影 ≥ 1×ATR）
4. 量价确认：量比 > 1.2 且收阴（无 volume 时跳过）
5. 温度计 > 30（过冷不杀跌）

### 均值回归增强（震荡态额外信号）

震荡态下，价格触及极端轨（VWAP ± k2×ATR）出现反转：
- 触极端上轨回落 → 强 S
- 触极端下轨反弹 → 强 B

## 五、v8 vs v9 对比

| 维度 | v8 | v9 |
|------|----|----|
| 价值锚 | 静态支撑阻力（随价格下移） | VWAP（日内水平不动） |
| S 触发条件 | 价格先站上阻力2根再回落（下跌永不成立） | 趋势向下 + 反弹至 VWAP 上轨遇阻 |
| B 触发条件 | LONGCROSS(支撑,C,2) 无过滤 | 趋势向上 + 回踩下轨 + 量价确认 |
| 趋势判断 | 无 | EMA20/60 + ADX 三态 |
| 量价验证 | 无 | 量比 + K 线形态 |
| 情绪 | RSI 仅评星 | 温度计加权门控 |
| 下跌趋势信号量 | ≈ 0 | 主动发 S |
| 震荡趋势信号量 | 过多（B 误发） | 收敛（需量价确认） |

## 八、风险与边界

1. **VWAP 依赖 volume**：若数据源无分钟级成交量，VWAP 退化为等权均价，效果打折但不崩溃。
2. **趋势滞后**：EMA/ADX 是滞后指标，趋势转折点会误判。用温度计 + 反转 K 形态做二次确认缓解。
3. **极端单边行情**：强趋势中 VWAP 会被持续突破，标准轨信号可能连续触发。靠冷却 + 日上限兜底。
4. **回测局限**：tickflow 的 intraday 接口对历史日期的支持需验证，回测可能只能走查近期数据。
