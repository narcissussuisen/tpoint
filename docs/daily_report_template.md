## 量化口径（agent 执行时必须照此计算，禁止自由发挥）

### 1. 综合达成度 P（%）
- **轮次权重**（按计划预期增益分配，合计 100）：R0 基建=5、R1 执行差异=15、R2 单位对齐=30、R3 ML灰度=20、R4 T0T借鉴=20、R5 regime=10
- **P = Σ(已完成轮次权重) + 当前轮权重 × 轮内完成度**
- **轮内完成度 = 已达成验收项 / 该轮验收项总数**（验收项以计划文件第二轮次表「验收标准」列为准；连续N日类按 已达天数/N 计，封顶 1.0）
- 进度条：10 格，█=P/10 取整，░ 补齐

### 2. 核心指标（滚动20交易日）
- 数据源：`data/roundtrip/*.jsonl` 最近 20 个交易日文件
- WR_prod_exec = source=live 中 ret_pct>0 占比 ×100；WR_recalc = source=recalc 同口径；G1 = WR_recalc − WR_prod_exec（pp）
- 任一侧 n<10 笔：该侧标「累积中」，G1 不计算（标 --）

### 3. 连续达标天数 k
- 读 `data/iteration_state.json` 的 consecutive_pass_days；达标定义=当前轮验收标准（计划文件）；R0=reconcile 当日自动生成；R1 起加 G1≤3pp（滚动）

### 4. 当日任务/次日计划来源
- 当日任务：从 `docs/iteration_log.md`、当日 memory 日志（`.workbuddy/memory/YYYY-MM-DD.md`）、git 提交记录提取
- 次日计划：计划文件当前轮的下一步 + 未完成待办（`.workbuddy/memory/MEMORY.md` 待办节）

### 5. 决策事项判定
- 计划文件标注「待用户拍板/待决策」项；或出现验收不达标连续 2 日、漂移>5pp、回滚分支时，必须列出并给建议选项
