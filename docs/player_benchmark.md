## 〇、tpoint 定义与使命（2026-09-28 晚立法，人审批准）

**定义**：tpoint = **分钟级做T信号哨兵**——在 watchlist 标的上实时识别「统计上优于随机的做T买卖点」，使 round-trip 配对在双边成本后的**长期净期望为正**。

三个基本推论：

1. **成功判据 = 配对经济学，不是点位精度**。tpoint 不是日内高低点预测器：日内极值只能事后确认，声称能稳定抄到最低/卖到最高的方法拟合的是运气（用户 2026-09-28 裁定：「事后查看发现抄到日内极值，说白了那是运气；日内做到差价利润才是模式内可达成的」）。选手模式同样不追求极值——K1 原文「吃中间差价，1~3 点利润即可，积少成多」。
2. **「模式内可达成」的反事实定义**：同日同标的随机 B/S 配对 = 运气基线；显著（z≥1.0 且 p<0.05 且 n≥30，random_control_validator 口径）且持续（rolling 20 交易日）超过该基线，才算模式内达成。单次/单日达标不作数。
3. **RSI 最终目标 = T0→T1→T2 逐级成真**；T2 全达（含 §六 晋升条件）=「tpoint 达到选手方法线」的正式宣告。

**量化四维**（验收只认这四维，锚点只准三个来源：K1-K7 条款锚 / 成本模型 / 随机基线+Δ，不拍脑袋）：

| 维 | 指标 | 锚点来源 |
|---|---|---|
| 频率 | 净胜率 net_wr（净>0 占比） | 随机基线 + 收敛线 |
| 期望 | 笔均净 mean_net（pp） | 成本模型（双边 0.116%）→ 成本倒挂消除线 |
| 质量 | 盈亏比 + 单笔净差 ≥+1% 达成率 | K1「1~3 点」（净 1% ≈ 毛 1.12%） |
| 纪律 | 尾端：中位止损 / 单笔最大亏损 | 选手止损纪律（−5% 硬割 / 实测最大亏 −3.00%） |

## 二、关键裁决：为什么不能用选手数字直接做 tpoint 阈值

1. **不同物种**：选手有金额读数的实测口径 = T+1~T+3 摆动（87.5/90.0% 是摆动口径，持仓周期均值 2.32 交易日、T+1 占 39/57）；tpoint = 分钟级做T 哨兵。把 87.5% 套到分钟做T 上 = 口径错配（同「固定持有 vs round-trip」同类错误）。注意：选手实际做T 频率高于披露（细节多未公开，用户 2026-09-28 纠偏），这**强化**而非削弱其做T 方法线（K1「1~3 点」+ 止损纪律）作为锚点的参考价值。
2. **账户级对标不可归因**：12.1 倍含选股、摆动、仓位管理全部贡献，无法分离出「做T 能力」单项。
3. **逐笔对照不可行**：选手披露可见做T 仅 5 笔（实际更多但细节未公开）且标的与 tpoint watchlist 不重合，可对照样本量为零。
4. 自述「共振下成功率 90%+」是给「共振」挂的修辞，非实测口径，不作阈值。

⇒ 选手数字只以两种方式进入验收：①K1「1~3 点/次」作**单笔目标锚**；②止损纪律（−5%/最大亏 −3%）作**亏损侧参照**。

### 稳健性条件（T1/T2 宣告适用，2026-09-28 晚立法）
任何一层的「达标」除满足上表阈值外，必须同时通过：
1. **jackknife 敏感性**：去掉样本中单笔最大绝对值 trip 后，各项指标结论不翻转（固化 backlog P1-20260928-single-trip-dominates-group-stats 教训：n≤30 时 1 笔极值可翻转整组均值，被单笔支配的「达标」不算达标）。
2. **跨 regime 分段不翻车**：样本按日型分段（阴跌 / 震荡 / 单边）后，各分段方向性判据不翻车——全天汇总口径不得掩盖结构性缺陷（固化 2026-09-28 300010 阴跌日案例，backlog P2-20260928-downtrend-entry-quality）。
3. 窗口口径 = rolling 20 交易日（与上表一致）；正式宣告的窗口要求见 §六。

### 不设的阈值（防口径错配）
- ❌ 账户级收益率对标（不可归因）；
- ❌ 摆动胜率 87.5/90.0% 平移到分钟做T（不同物种）；
- ❌ 「成功率 90%+」自述修辞。
