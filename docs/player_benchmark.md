## 二、关键裁决：为什么不能用选手数字直接做 tpoint 阈值

1. **不同物种**：选手有金额读数的实测口径 = T+1~T+3 摆动（87.5/90.0% 是摆动口径，持仓周期均值 2.32 交易日、T+1 占 39/57）；tpoint = 分钟级做T 哨兵。把 87.5% 套到分钟做T 上 = 口径错配（同「固定持有 vs round-trip」同类错误）。注意：选手实际做T 频率高于披露（细节多未公开，用户 2026-09-28 纠偏），这**强化**而非削弱其做T 方法线（K1「1~3 点」+ 止损纪律）作为锚点的参考价值。
2. **账户级对标不可归因**：12.1 倍含选股、摆动、仓位管理全部贡献，无法分离出「做T 能力」单项。
3. **逐笔对照不可行**：选手披露可见做T 仅 5 笔（实际更多但细节未公开）且标的与 tpoint watchlist 不重合，可对照样本量为零。
4. 自述「共振下成功率 90%+」是给「共振」挂的修辞，非实测口径，不作阈值。

⇒ 选手数字只以两种方式进入验收：①K1「1~3 点/次」作**单笔目标锚**；②止损纪律（−5%/最大亏 −3%）作**亏损侧参照**。

## 三、验收阈值（三层，T0 为一票否决前置）

### T0 · 环境前置（一票否决）
验收数字必须全部产自修复后验证栈：
- 随机对照一票否决：p<0.05 且 z≥1.0 且 n≥30（random_control_validator，修复口径）；
- 收益口径 = simulate_position_sm round-trip（底仓模型 + cost_for_symbol 双边成本）；
- 信号链 = 生产同源（detect_signals_general + 生产 config / detect_for replay gates='prod'）；
- 数据源 = F 盘真实 1m 并标注；降级/兜底口径日不得用于验收；
- samebar 偏差：修复前所有数字强制标注「samebar 口径，系统性偏乐观」。

### T1 · 合格线（哨兵可用）
| 指标 | 阈值 | 口径 |
|---|---|---|
| 净胜率 | ≥ **55%**（rolling 20 交易日） | round-trip 修复口径，n_trips≥30 |
| 笔均净收益 | **> 0** | 同上；成本倒挂的硬性消除线 |
| 显著性 | 显著胜随机（z≥1.0 且 p<0.05） | 随机对照 |

### T2 · 选手方法线（对齐 K1「1~3 点/次」）
| 指标 | 阈值 | 锚点 |
|---|---|---|
| 净胜率 | ≥ **60%**（rolling 20d，n_trips≥30） | positioning.md 收敛线的正式化 |
| 盈亏比 | ≥ **1.2** | positioning.md 既有合格线 |
| 单笔净差 ≥+1% 达成率 | ≥ **40%** | K1「1~3 点利润」：净 1% ≈ 毛 1.12%（双边成本 0.116%） |
| 笔均净收益 | 稳定 > 0（rolling 20d 无连续 5 日为负） | 成本倒挂消除的持续态 |
| 单笔最大亏损 | 中位止损 ≤ **−1.5%**，无超过 −5% 的未止损持仓 | 选手止损纪律（−5% 硬割/实测最大亏 −3%）的分钟级映射 |

### 不设的阈值（防口径错配）
- ❌ 账户级收益率对标（不可归因）；
- ❌ 摆动胜率 87.5/90.0% 平移到分钟做T（不同物种）；
- ❌ 「成功率 90%+」自述修辞。
