一、命名规范定义

类别规范示例
语义化版本号MAJOR.MINOR.PATCH，记录于 VERSION9.1.0（9=策略世代, 1=因子迭代, 0=补丁）
Git 标签v<MAJOR>.<MINOR>.<PATCH>v9.0.0, v9.1.0
Git 分支main（生产）/ feature/<topic> / fix/<topic> / refactor/<topic>main, feature/factor-v3
核心模块文件纯功能名，不带版本前缀；版本由 VERSION 统一管理indicators.py（非 v9_indicators.py）
脚本文件<功能>_<变体>.pyplayback_gl_0709.py
回测文件backtest_<功能>.py 统一前缀backtest_extended.py
数据文件运行态无版本前缀；归档数据用 <功能>_<YYYYMMDD>.<ext>metrics.json, playback_gl_20260713.json
计划任务tpoint_<功能> 前缀tpoint_monitor
锁文件tpoint_monitor.lock / tpoint_monitor.pid系统临时目录
环境变量TP_* 前缀（原 V9_*）TP_PROMPT_FILE
