# DET 信号质量评估体系 v2.0 —— 日内分时「抓顶底」口径统一

> 状态：待量化专家评审（loop gate）
> 目标战场：A 股日内分时（9:30–15:00，约 240 根 1m bar）
> 评价对象：信号在给定分时窗口内「抓顶底」的能力，**不是**预测涨跌方向的能力
> 取代：`tpoint_v10.5.0_release.md` §4 中口径混杂的 DA/EHR 标注

---

## 0. 核心结论（先给判定）

1. **抓顶底 = 触及 + 邻近**，数学上对应「触达型 / 邻近型」，**不**对应「净方向型」。
2. **净方向型（DA_net，`mu > -md`）从信号质量评价中退役**：它衡量的是「涨跌预测」（硬币翻转，结构性 ≈50%），会系统性低估抓顶底能力（例：抓到 +5% 的顶、随后 -6% 反向波动，抓顶成功但净方向判失败）。
3. 评价指标拆成**三个正交维度 + 一个理论边**，动态阈值自适应日内分时波动。
4. **含未来函数的指标（精度/邻近）只准盘后回测**，绝不进实盘触发。

---

## 1. 指标重新定义（三层 + 理论边）

### 1.1 Attainment — 触达命中率（原「DA-触碰型」的泛化）

**衡量**：信号方向的目标位是否在窗口内被「摸到过」。这是抓顶底的一阶能力（有没有触及目标）。

对 B（抓底）信号，入场价 `p`，前向窗口 `H` 根：

```
up_touch   = max(high[i+1 : i+H]) >= p * (1 + X)   # 触及用日内 high
down_touch = min(low[i+1 : i+H]) <= p * (1 - Y)    # 触及用日内 low
```

- 抓底兑现视角：`up_touch`（买入后上方目标被触及）→ 记 `Attain_B`
- 抓顶兑现视角（S 信号）：`down_touch`（卖出后下方目标被触及）→ 记 `Attain_S`

- **双向触达**：`X` / `Y` 分别记录「抓顶成功率」与「抓底成功率」，不合并。
- **口径**：触达用 **high/low**（触及目标位看日内真实高低点）；兑现/理论边用 **close**（可成交价，见 §1.3/1.4）。
- **动态阈值**（见 §3）：`X` / `Y` 默认用 ATR 比例，而非固定 0.15%。

### 1.2 Precision — 极值邻近精度（原「EC-邻近型」）

**衡量**：信号触发点距离「信号后局部窗口内的真实极值」有多近——回答「抓得准不准」。

```
局部窗口 = 信号后 W_PREC 根（默认 30，i+1 起=真极值必在信号之后，消除开天眼）
B(抓底): 真底 = min(low[i+1 : i+1+W_PREC])；命中 = (p - 真底)/真底 <= delta_eff
S(抓顶): 真顶 = max(high[i+1 : i+1+W_PREC])；命中 = (真顶 - p)/真顶 <= delta_eff
```

- **时间先后约束（防空开天眼）**：窗口从 **i+1 起**（不含信号 bar 自身，避免把「信号 bar 的 low」当「真底」导致 lag=0 自洽开天眼）；尾部不足 W_PREC 根的信号剔除。
- `delta_eff = max(0.5%, c2 × ATR_n/p)`：加 0.5% 下限保底（个股 ATR 常仅 0.1–0.3%，纯 ATR 比例容差过小、邻近率失真）。
- ⚠️ **含未来函数**：真极值是窗口结束才知道。仅盘后回测评估算法对极值的敏锐度，**禁止作实盘触发条件**。

### 1.3 Capture — 兑现率（原「EHR-触达型」）

**衡量**：入场后实际获得的有利波动空间是否达标——回答「抓到后赚没赚到」。

```
B: max(c[i+1:i+H]) / p - 1 >= eps_dyn     （上方获利空间 ≥ eps_dyn）
S: 1 - min(c[i+1:i+H]) / p >= eps_dyn     （下方获利空间 ≥ eps_dyn）
```

- 与 1.1 的差别：1.1 是「是否触及目标位」（阈值是**入场价+目标**），1.3 是「获利空间是否够大」（阈值是**动态 eps**）。二者独立，可交叉出「触及但空间不足」的信号。

### 1.4 TEP — 理论边（保留，口径统一为「扣成本」）

```
B: edge = max(c[i+1:i+H]) / p - 1 - COST
S: edge = 1 - min(c[i+1:i+H]) / p - COST
TEP = P(edge > 0)
```

- `COST = 0.0005`（佣金万1×2 + 滑点，与成本模型一致）。
- 旧 release §4 的「TEP pos_rate 100%」= **不计成本**版；本 run 扣成本 + close 口径实测：**信号等权 84.1% / 标的等权 87.7%**。统一采用**扣成本 + close** 口径。

## 3. 动态阈值方案

日内分时波动早盘剧烈、午盘横盘，固定阈值不公平。双轨制：

| 口径 | 阈值来源 | 公式（n=信号前 20 根） | 适用 |
|---|---|---|---|
| 绝对口径（可比） | 固定值 | X=Y=0.15%、eps=δ=0.5% | 跨标的/跨日横向比较 |
| **相对口径（主判据）** | ATR 比例 | `X = Y = k * ATR_n / p`；`eps_dyn = c1 * ATR_n / p`；`delta_dyn = c2 * ATR_n / p` | 日内自适应抓顶底 |

- 默认系数（可调，冒烟已校准）：`k = 1.0`（触达 1×ATR，专家口径 p±1×ATR 触顶/底）、`c1 = 1.5`（兑现 1.5×ATR，须 > k 避免与触达退化重合）、`c2 = 1.0`（邻近 1×ATR，且 `delta_eff = max(0.5%, c2×ATR/p)` 保底）。
- `ATR_n = mean(max(h-l, |h-pc|, |l-pc|))` 于信号前 n 根。
- 回测两口径都算，**主判据用相对口径**；绝对口径仅作绝对水平参照。
- ⚠️ 校准教训：初始 `k=0.5/c1=0.5/c2=0.25` 冒烟暴露三问题——① k=c1 致触达=兑现退化；② 0.5×ATR 触达阈值过小致 95% 无区分度；③ 0.25×ATR 邻近容差过小致邻近率 17%。已改 k=1.0/c1=1.5/c2=1.0 并加 0.5% 下限。

## 4. 未来函数与实盘边界（关键纪律）

| 指标 | 未来函数 | 实盘可用 |
|---|---|---|
| Attainment（固定阈值 X） | 无（价格是否已 ≥ p×(1+X) 实时可判） | ✅ 信号 gate |
| Capture（固定 eps） | 无 | ✅ 出场/兑现监控 |
| **Precision（邻近真极值）** | **有**（需窗口结束的 min/max） | ❌ 仅盘后回测 |
| TEP | 无 | ✅ 理论边参照 |

**硬规则**：任何含「窗口真极值 min_H / max_H」的指标，只用于盘后评估算法敏锐度，严禁进入 `monitor` 实时触发链路。

## 5. 综合评分（精度 × 兑现）

单指标无法回答「既抓得准、又赚得到」。建议双层：

```
信号质量综合分 = Precision(准度) × Capture(效度)    # 盘后回测
实盘信号 gate   = Attainment(固定阈值) 达标           # 实时
```

- 盘后用综合分排策略优劣；实盘用 Attainment 做信号前置门控，出场侧负责兑现（呼应 P3 出场治理主线）。

## 6. 决策与校准记录

1. **动态系数**：用户初拍 `k=0.5/c1=0.5/c2=0.25` → 冒烟暴露退化（k=c1 触达=兑现、阈值过小、邻近率 17%）→ 校准为 **`k=1.0/c1=1.5/c2=1.0`** + 邻近 `max(0.5%, c2×ATR/p)` 下限。
2. **主 horizon**：锁定 **to-EOD**（信号→当日收盘），30/60/120 作成熟度剖面。
3. **综合分权重**：纯乘法 **1.0×Precision × 1.0×Capture**（基线，后期按交易风格再加权）。
4. **Precision 窗口**：前向 `W_PREC=30` 根局部窗口（只往前看，消除开天眼），非 to-EOD 全程。
5. 敏感性分析：单参数局部扰动（k/c1/c2/W_PREC 四维），判定 ROBUST（无尖峰、单调平滑）。

## 8. 业务硬约束与认知锚点（用户 2026-08-23 拍板）

### 8.1 W_PREC 硬锁定 = 30（严禁优化）
- **抓顶底的定义 = 看信号后 30 根 K 线**（约 30 分钟做T持有周期），这是业务核心硬约束，不是可调参数。
- 邻近率对 `W_PREC` 固有敏感（20→40 根 69.2%→58.1%），一旦纳入自动优化参数池，优化器会通过调它「曲线救国」制造虚假增益 → 过拟合。
- **代码已落实**：`evaluate_signal_validity_v2.py` 移除 `--w-prec` 入口，`W_PREC=30` 硬编码常量；`sweep_signal_validity_v2.py` 中 W_PREC 仅作诊断维度（非优化）。
- **优化参数池 = {k, c1, c2}**（触达/兑现/邻近容差的 ATR 系数），仅这三个可进自动优化。

### 8.2 综合分门槛认知（避免误判）
- 当前基线（187 标/6000 日，close 口径）：
  | 口径 | Precision | Capture | 综合分 |
  |---|---|---|---|
  | 信号等权 | 65.4% | 71.4% | 46.7% |
  | 标的等权 | 59.0% | 72.6% | 42.8% |
- **综合分 = Precision × Capture**（准度 × 效度），45% 左右 = 「约 65% 抓顶底精度 × 71% 兑现效度」的乘积，是**健康基线**，**不代表策略无效**。
- **增益判据**：后续迭代（T0T、Regime 门控等）后，若综合分**显著提升（如 +3pp 至 50%+）**，才代表策略真有增益；不要把 <50% 误读为「无效」。

### 8.3 P2 泛化重点：缩小「信号等权 vs 标的等权」差异
- 当前差异：综合分 信号等权 46.7% > 标的等权 42.8%（差 3.9pp）。
- **拆解**：差异几乎全在 **Precision**（65.4% vs 59.0%，差 6.4pp），而 **Capture 几乎无差异**（71.4% vs 72.6%）——说明**少数活跃标的贡献了更高的抓顶底精度**（拉高信号等权），但**兑现能力是全池普适的**。
- **P2 目标**：验证 DET v2.0 在 187 标上的普适性。核心验收 = **缩小这个差异**（使抓顶底精度也普适化），或**明确接受并量化**「活跃标的带动的超额精度」——不能让它成为隐藏的样本偏置。
