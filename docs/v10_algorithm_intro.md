# tpoint v10.0.0 算法简介（2026-08-05）

> 一分钟读懂版：tpoint 是 A股/LOF/ETF 日内做T信号系统——**在真实波动里找「跌过头/涨过头」的拐点**，用一组相互独立的过滤器把关信号质量，只做「净收益能盖过成本」的 T。

## 信号链（每一层都可独立灰度/回滚）

```
1m 行情(mootdx)
  → ① 信号源 miji_alpha：均线引力(价格偏离VWAP) + MACD背离 + 价格地板/天花板
  → ② 门控：ATR 波动下限(0.25) + mpr60 大周期方向过滤
  → ③ v10.0.0 量能确认：B 须缩量回调(量比≤1.2×MA20，抛压衰竭)；S 须平量以上(≥1.0×，放量滞涨)
  → ④ v9.4.0 结算闸门：T+1 个股每方向每日限 1 次完整往返（防底仓磨损）；T+0 LOF/ETF 不限
  → ⑤ 飞书卡片推送（ACK 落账 push_audit，断流写后缓冲自愈）
出场：移动止损 TRAIL（浮盈 0.4% 激活 / 回撤 0.6% 锁定）+ 对手信号出场 + 收盘强平
```
