## 二、每轮迭代的因子组合/参数方案

### R-A（I1，2 个交易日）：零信号归因 + 门槛寻优加宽
- 用 factor_optimizer 对 161129/513310 跑**联合网格**：atr_min_pct {0.10,0.15,0.25} × TP_MHD_THRESHOLD {0.08,0.10,0.15} × mpr {关,[60]}
- 定位卡死闸门（哪道门控吞掉全部触发）；输出最小松绑组合
- 护栏：单日信号数 ≤12、全集口径（5只池净胜率）不降 ≥1pp 才热更

### R-B（I1/I5，3-5 个交易日）：高低点反转因子离线立项
- 候选因子（手册+经典，按分钟级可算性筛选）：
  1. **RSI(14,1m) 超买超卖反转**：RSI>80 回落拐 S、RSI<20 回升拐 B（用户点名方向）
  2. **KDJ(9,3,3,1m)**：J 值极端反转（J>100 拐 S / J<0 拐 B）
  3. **主力波动率（放量上涨/放量下跌段）**（手册 fitness 2.07，分钟K线构造）→ 做波动段确认/过滤
  4. **日内成交量分布/高低位成交占比**（手册：单一成交额占比熵 fitness 2.15，30min 最优）→ 高位放量滞涨拐 S 辅助
- 验证方式：作为**独立触发源**离线重放 F盘全历史 → 与现有引擎信号取并集测增益；单独测因子级命中率
- 纪律：先离线两段式（tune_pool_40 + watchlist），通过才以小版本灰度 1 只

## 三、回测验证标准与评估指标

| 指标 | 口径 | 达标线 |
|---|---|---|
| 净胜率（主） | round-trip 净>0 占比，成本=万一+印花+滑点2bps | 池级中位 ≥56.2%（C_prod）；候选 ≥ 基线+1pp（薄样本+2pp） |
| 盈亏比 | avg_win/avg_loss | ≥1.5 且不劣于基线 |
| 总收益率 | 全历史累计净收益 | >基线且不依赖单日极端值（去最大单日贡献后仍>0） |
| 最大回撤 | 逐日净值 | ≤基线+2pp |
| 夏普 | 日收益序列 | ≥基线 |
| 信号数 | 日均推送 | 1~12 笔/标的（低于1=门槛仍死，高于12=过松刷屏） |
| 全集口径不降 | 5只池级净胜率 | 任何变更硬约束 |

两段式：tune_pool_40 调参 → watchlist 5 只验证；薄样本（<80d）结论带水印、门槛加倍。
