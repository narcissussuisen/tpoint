## 3. 核心洞察

1. **市场 regime 决定方向**：这 79 天是下行行情，先卖（反T）赚钱、先买（正T）接飞刀。
2. **基金方向分化最极端**：反T WR 69.3% vs 正T WR 30%（差 39pp）——基金（原油 LOF、中概 ETF）是趋势性标的，下行趋势中方向对了大赚、错了大亏。
3. **个股方向分化较小**：反T 64.3% vs 正T 50%（差 14pp）——个股波动大、趋势弱。
4. **个股 S 信号 Prec 49% 接近随机，但反T 仍赚钱**——因为下行趋势天然占优，即使抓顶精度接近随机，"先卖后买"也占便宜。

## 4. 对实盘 / R4 的意义（重大）

1. **当前应反T 为主，正T 谨慎**（下行行情接飞刀）。
2. **regime 门控是治「基金正T 巨亏 -802.8%」的关键**——它抑制下行行情的 B 信号（正T 开仓），正是对症。
3. **R4a（三条件止损）应针对反T 重跑**，不是正T——反T 是赚钱方向，止损优化才有意义。
4. **R4b（入场过滤）应优先治理个股 S 信号（Prec 49%，最弱象限）**。
5. **生产的 56.2% WR 完全解释通**：它是双向（反T 69.3% 拉高 + 正T 30-50% 拉低）。
