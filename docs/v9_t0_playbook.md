# v9-miji 正向 T+0 操作演练手册

> 适用系统：v9 监控（monitor_v9.py + v9_indicators.py + v9_exit_manager.py）
> 角色澄清：v9 是 **监控 + 预警 + 持仓跟踪** 系统，**不自动下单**。实际买卖在券商终端手动执行；v9 在 B 信号触发时自动在 `data/v9_state.json` 记录开仓，在 EXIT 触发时自动记录平仓。
> 前提：正向 T 需你已持有该标的**底仓**。当日逢低买入等量份额，待信号出现后卖出等量份额，保留底仓、赚取日内差价。

---

## 0. v9 的"操作界面"与功能模块

| 模块 | 路径 / 入口 | 用途 |
|------|------|------|
| **飞书预警卡片** | 飞书群 | 主界面。B（🟢买入）/ S（🔴卖出提醒）/ X（🔵EXIT 平仓）三类信号，含价格、星级、RSI、情绪温度、触发原因 |
| **信号流水** | `data/v9_signal.txt` | 所有信号按时间 append 留存，可回看 |
| **持仓状态** | `data/v9_state.json` | `pos_{标的}` 记录当前持仓（入场价/持仓高点/触发原因/止损价），跨重启持久化 |
| **心跳状态** | `data/v9_metrics.json` | 服务存活、扫描耗时、错误数、标的数 |
| **扫描明细** | `logs/monitor_console.log` | 每标每轮：n（bar数）/未检查/ b_match / s_match / 持仓Y/N |
| **生命周期** | `logs/monitor_lifecycle.log` | 启动、抢锁、退出记录 |
| **券商交易终端** | 你自己的交易软件 | 实际下单（买入/卖出），v9 不替代 |

## 1. 买入阶段（B 信号触发）

### 1.1 买入时机 —— 看飞书 B 卡片
B 信号由 `v9_indicators.check_b_trigger` 判定，必须**同时满足**：
1. `trend[i] == 1`（EMA20 > EMA60 且 ADX > 20，处于上升通道）
2. 反转形态：**收阳** 或 **长下影 ≥ 0.5·ATR**
3. 触及下轨：前一根 close/low 戳破 `下轨 = VWAP − K1·ATR`（K1=1.0），当前收回上方 → 原因 `回踩下轨`
   - 或极端情形：当前 low 戳破 `VWAP − K2·ATR`（K2=2.0）且长下影 ≥ 1·ATR → 原因 `极端超卖反弹`
4. 量价确认：若数据源有量，`量比 ≥ 2.0`（VOL_THRESHOLD）才放行，否则判 `量不足` 不发

飞书卡片示例：
```
🟢 某某股份 BUY ★★☆ [回踩下轨]
现价 48.85（−2.3%）
下轨 48.80  RSI=42  温度=35
```
- **星级**：B 越冷越强（温度<30→3星，<45→2星）；量比≥1.5 加 2 星、≥1.2 加 1 星。★★★/★★☆ 优先跟。
- **温度** 35 < 45 → 2 星基础；量比若 1.6 → 加 1 星 = ★★☆，属于可跟级别。

### 1.2 买入数量 —— 由你手动决定（v9 不计算仓位）
v9 只跟踪，不替你定数量。原则：
- **≤ 底仓数量**：正向 T 要求买的份额 ≤ 你已有的底仓，确保当日可卖平。
- **≤ 可用资金 / 现价**：单笔占用资金不超账户比例（建议单标 T 仓位 ≤ 可用资金的 20%~30%）。
- 单标每日 B 上限 `MAX_B_DAILY = 12`，两次 B 之间冷却 `COOLDOWN = 120s`（同标的同方向）。

### 1.3 执行买入（券商终端）
1. 打开券商终端，输入标的代码。
2. 买入价：建议**限价贴近 B 信号现价**（如 48.85 ± 0.02），避免追高。
3. 数量：按 1.2 测算的 T 份额（如 1000 股）。
4. 下单 → 成交流水留存。

### 1.4 系统自动动作
B 信号触发瞬间，`detect_for` 已在 `v9_state.json` 写入：
```json
"pos_300975.SZ": {
  "entry_price": 48.85, "entry_idx": 123,
  "max_fav": 48.85, "entry_reason": "回踩下轨", "stop_price": -1e9
}
```
> `stop_price = -1e9` 是因为生产 `use_stop=False`（硬止损关闭）。你可在 `data/v9_signal.txt` 看到这条 B 记录。

## 2. 持仓监控（持仓管理要点）

v9 每轮扫描（并发拉取，约 6s/轮）持续跟踪 `pos_{标的}`：

### 2.1 盈亏监控
- `max_fav` 实时刷新为**持仓期间最高价**（浮动盈利高点）。
- 浮盈% = `(max_fav − entry_price) / entry_price × 100`。
- 飞书不直接每轮报盈亏，但你可在 `logs/monitor_console.log` 看每轮 `持仓=Y` 及 `b_match/s_match`；EXIT 触发时一次性结算盈亏。

### 2.2 风险控制（出场管理 = "秘籍"）
生产配置（`EXIT_CFG`）：
```python
make_config(use_stop=False, use_time=False, use_trailing=True,
            trail_activate_pct=0.4, trail_pct=0.6, s_signal_exit=True)
```
出场优先级：**硬止损(关) > S 信号出场(开) > 移动止损(开) > 时间止损(关)**

**移动止损（核心保护）**：
- 激活条件：浮盈 ≥ `trail_activate_pct = 0.4%`
- 触发平仓：价格回落至 `移动止损线 = max_fav × (1 − trail_pct/100) = max_fav × 0.994`，且移动止损线 > 硬止损价
- 例：max_fav 到 49.50 → 浮盈 1.33% ≥ 0.4% 已激活 → 移动止损线 = 49.50×0.994 = **49.20**。价格守在 49.20 上方持有；跌破 49.20 → 触发 TRAIL 平仓。

**风险要点（操作员牢记）**：
- v9 只**提示** EXIT，平仓需你手动在券商终端执行。看到 🔵 EXIT 应立即卖，不要等。
- 因硬止损/时间止损关闭，若价格**未触发移动止损也未出 S 信号**，持仓会一直保留到收盘——此时按你自己的风控（如尾盘强平）处理，v9 不会自动清仓。
- 单仓位模型：同一标的同一时刻只持一仓，期间不再发新 B（避免加仓摊薄）。

## 3. 卖出阶段（EXIT 信号）

### 3.1 卖出信号判断标准
v9 在持仓中每根 bar 检查两条出场路径：

**路径 A — S 信号出场（自然目标，默认开）**
- `check_s_trigger`：`trend[i] ∈ {−1, 0}`（下降/震荡）+ 反转形态（收阴/长上影≥0.5·ATR）+ 触及上轨（`上轨 = VWAP + K1·ATR`）→ 原因 `反弹遇阻` / `极端超买回落`
- 飞书：`🔵 XXX EXIT [S] [回踩下轨]` 现价 price 触及上轨 level RSI temp

**路径 B — 移动止损（浮盈保护，默认开）**
- 浮盈≥0.4% 且价格跌破 `max_fav×0.994` → 原因 `TRAIL`
- 飞书：`🔵 XXX EXIT [TRAIL] [回踩下轨]` 现价 price 移动止损线 level RSI temp

### 3.2 卖出时机选择
- **优先跟 EXIT 卡片**：无论 TRAIL 还是 S，都是 v9 判定的离场点，见卡即走。
- **TRAIL**：锁定利润，适合利润已跑出来、怕回吐的场景——不要贪，跌破移动止损线就卖。
- **S**：价格冲到上轨遇阻，适合吃一波反弹的离场。
- 若同根 bar 同时满足多条，v9 按优先级只推一条（硬止损>S>移动>时间），以卡片原因为准。

### 3.3 执行卖出（券商终端）
1. 收到 🔵 EXIT 卡片，确认原因（TRAIL / S）与现价、移动止损线/上轨。
2. 券商终端**卖出等量 T 份额**（与 1.3 买入数量一致，如 1000 股）。
3. 卖出价：限价贴近卡片现价；TRAIL 场景价格已在回落，挂单稍低于现价确保成交。
4. 成交流水留存 → 本轮正向 T 完成。

### 3.4 系统自动动作
EXIT 触发后，`detect_for` 将 `pos_{标的}` 置为 `None`，`v9_state.json` 不再有该标的持仓；`v9_signal.txt` append 一条 X 记录。下一轮扫描该标的回到"空仓可发 B"状态（受冷却与每日上限约束）。

## 4. 操作记录：一次完整正向 T 演练（示例）

> 标的以 `300975.SZ` 演示（实际由你自选，v9 不代选）。假设昨收 PC=50.00，你持有底仓 5000 股。

### 步骤 1 · 等待 B 信号
- 时段：下午 13:10，v9 并发扫描中（`data/v9_metrics.json` 显示 `status=running`，`scan_s≈6`）。
- 飞书弹卡：
  ```
  🟢 300975 BUY ★★☆ [回踩下轨]
  现价 48.85（−2.3%）
  下轨 48.80  RSI=42  温度=35
  ```
- 系统自检：trend==1 ✓、长下影 ✓、前根戳破下轨收回 ✓、量比 1.6≥2.0？→ 注意：若量比<2.0 会被判"量不足"不发；本例假设量比 2.3 放行。

### 步骤 2 · 执行买入
- 券商终端：买入 `300975.SZ` **1000 股**，限价 48.85。
- 关键参数：数量=1000 ≤ 底仓 5000 ✓；占用资金 48,850 ≤ 单标额度 ✓。
- 系统动作：`v9_state.json` 写入 `pos_300975.SZ`（entry=48.85, max_fav=48.85）。`v9_signal.txt` 追加 B 记录。

### 步骤 3 · 持仓监控
- 13:10–13:40 价格震荡上行，最高摸到 49.50。
- v9 内部：max_fav 更新为 49.50；浮盈=(49.50−48.85)/48.85=**1.33%** ≥ 0.4% → **移动止损激活**。
- 移动止损线 = 49.50 × 0.994 = **49.20**。
- 监控要点：价格守在 49.20 上方则持有；一旦跌破 49.20 即触发 TRAIL。

### 步骤 4 · 卖出信号
- 13:42 价格冲高后回落至 49.16，跌破移动止损线 49.20。
- 飞书弹卡：
  ```
  🔵 300975 EXIT [TRAIL] [回踩下轨]
  现价 49.16（+0.6%）
  移动止损线 49.20  RSI=55  温度=52
  ```

### 步骤 5 · 执行卖出
- 券商终端：卖出 `300975.SZ` **1000 股**，限价 49.16。
- 本轮 T 利润 ≈ (49.16 − 48.85) × 1000 = **+310 元**（未计手续费）。
- 系统动作：`pos_300975.SZ` 清空；`v9_signal.txt` 追加 X 记录。底仓仍为 5000 股，正向 T 完成。

### 步骤 6 · 复核（建议每次做完核对）

## 5. 关键参数速查表

| 参数 | 值 | 含义 |
|------|----|------|
| K1 | 1.0 | 标准轨倍数（下轨=VWAP−K1·ATR） |
| K2 | 2.0 | 极端轨倍数（均值回归用） |
| ATR 周期 | 14 | Wilder ATR |
| EMA_FAST / SLOW | 20 / 60 | 趋势快慢线 |
| ADX_THRESHOLD | 20 | 趋势有效门槛 |
| VOL_THRESHOLD | 2.0 | 量比确认门槛（低于则"量不足"） |
| TEMP_COLD / HOT | 30 / 70 | 情绪温度计冷/热分界 |
| COOLDOWN | 120s | B/S 同标的同方向冷却 |
| MAX_B_DAILY / MAX_S_DAILY | 12 / 12 | 每日信号上限 |
| trail_activate_pct | 0.4% | 移动止损激活浮盈 |
| trail_pct | 0.6% | 移动止损回撤比例 |
| use_stop / use_time | False / False | 硬止损 / 时间止损（生产关闭） |
| use_trailing / s_signal_exit | True / True | 移动止损 / S 信号出场（生产开启） |

---

## 6. 注意事项
1. v9 **不自动下单**，EXIT 卡片是提示不是委托，需你手动卖出。
2. 硬止损、时间止损当前**关闭**，尾盘若仍持仓需自行处理（如 14:55 强平）。
3. 单仓位模型，持仓中不再发新 B，避免加仓。
4. 数据源（Mootdx/通达信）若返回 0 行，信号会停摆——`v9_metrics.json` 中 `errors` 上升或 `scan_s` 异常时先查数据源。
