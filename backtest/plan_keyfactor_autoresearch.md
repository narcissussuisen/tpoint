## 1. autoresearch 架构与核心算法（已核实，来源 github.com/karpathy/autoresearch）

| 组件 | 角色 | 是否可改 |
|---|---|---|
| `prepare.py` | 固定常量、一次性数据准备、运行时工具（含冻结评估 `evaluate_bpb`）| **不可改**（评估冻结，保证诚实+可比）|
| `train.py` | 完整 GPT 模型 + 优化器（Muon+AdamW）+ 训练循环 | **Agent 唯一可编辑文件** |
| `program.md` | 给 Agent 的目标/约束说明（人类写）| 人类迭代 |

**核心循环（Ratchet Loop）**：Agent 读 `program.md` → 改 `train.py` → 跑**固定 5 分钟墙钟预算** → 用冻结指标 `val_bpb`（越低越好、与词表大小无关）→ 改进则 `git commit` 保留、否则 `git reset` 回滚 → 重复。设计要点：单一可编辑文件、冻结评估指标、固定预算（跨平台直接可比，~12 实验/小时、~100/夜）、结果落 `results.tsv` + `analysis.ipynb` 出 `progress.png`。

## 3. 目标定义 + 因子确认数值手册（回答 Q1/Q2）

### 3.1 "关键因子"要确定的两件事
1. **三因子重要性排序**：引力 / 量价背离 / MACD 背离，哪个真驱动信号质量？
2. **各因子数值门槛的最优/鲁棒区间**（尤其 0.8 引力倍数、1.2/0.8 量比、共振阈值 2）。

### 3.2 因子确认数值手册（来自 v9.1.0 代码 core/miji_alpha.py 第 1–441 行）

**① 引力 Gravity**（参数 `VWAP_DEV_BUY=0.8` / `VWAP_DEV_SELL=0.8`，`ATR_PERIOD=14`）
- 买（急跌不杀）：`c[i] <= vwap[i] - 0.8*atr[i]`
- 卖（急拉不追）：`c[i] >= vwap[i] + 0.8*atr[i]`
- **"弹到什么程度为极限"** = 价格偏离 VWAP 达 **0.8 × ATR**。本研究要"确定"的就是这个 0.8 倍数该定多少（扫描）。

**② 量价背离 Vol_Div**（参数 `DIVERGENCE_W=20` 局部极值回看、`VOL_COMPARE_W=10` 近10 vs 前10 均量、`VOL_EXPAND_RATIO=1.2`、`VOL_SHRINK_RATIO=0.8`）
- **底部确认**：价格创局部新低（`lo[i] <=` 窗口20根内最低）**且** 量比 `近10根均量/前10根均量 >= 1.2`（放量恐慌）
- **头部确认**：价格创局部新高（`h[i] >=` 窗口20根内最高）**且** 量比 `<= 0.8`（缩量）

**③ MACD 背离 Macd_Div**（参数 `MACD_FAST=12`/`SLOW=26`/`SIGNAL=9`、`LOCAL_W=15`）
- **底部确认**：价格创局部新低 **且**（绿柱收缩 `hist<0 且 hist[i]>hist[i-1]` **或** 金叉 `dif[i]>dea[i] 且 dif[i-1]<=dea[i-1]` **或** DIF 拐头向上）
- **头部确认**：价格创局部新高 **且**（红柱缩短 `hist>0 且 hist[i]<hist[i-1]` **或** 死叉 **或** DIF 拐头向下）

**④ "显示阈值"（Q1 末问，澄清）= 共振阈值 `RESONANCE_THRESHOLD=2`**
即"几个因子同向才触发"：默认 **≥2/3 票**。这是**信号门槛**（几票通过），不是因子内部数值。每个因子还有自己的数值门槛（上面 ①②③）。"确定关键因子"= 弄清①哪几个因子真有用 ②这些数值该定多少。本研究的阈值扫描覆盖：0.8 引力倍数、1.2/0.8 量比、共振阈值 2、MACD 三参。

### 3.3 前向收益 skill 简介（回答 Q2）
- **定义**：对**每个信号**（B 或 S），计算其后 **N 根**（如 6/12/24 根 1 分钟）的收益率。B 信号后理应上涨（前向收益为正）、S 信号后理应下跌（为负）。
- **"skill" = 信号的前向预测力**：这个信号是否真的"领先于它声称的那段行情"？
- **为什么用它做冻结指标**：我们前期最大坑是 B/S **在时间上完全分离**，凑不成 round-trip（配对 PnL 无法算）。前向收益**不需要配对**——每个信号独立评估质量。故它是评估"因子重要性"的最佳冻结指标（替代 round-trip 净值）。

- **universe = 大A股非ST标的（~4000+ 只）**；20 只本地股 / 58 只 broad_open **只是随机抽样/小训练集，不是 universe**。
- "全量下载整个 universe" 不现实（数千票 × 5000 1m）。故**数据集 = 从 universe 分层抽样出的训练集**。
- **抽样方案（待确认样本量）**：按市值分层（大/中/小盘）+ 行业分层 的**分层随机抽样**；起始训练集建议 **200–300 只**（平衡覆盖与下载耗时）。全 universe 是泛化目标，后续用样本代理验证。

- **指数（Q5）**：最同步大盘指数**待测决定**——对候选（000300 沪深300 / 000001 上证 / 399001 深证成指 / 000905 中证500 等）做**相关性/同步性测试**，选与训练集信号最同步者。该指数用于潜在门控基准或行情 regime 标注。
- 落地到 `backtest/keyfactor_data/`。**先验证 tickflow 连通性 + 抽样清单，再批量拉数**。

**Phase 2 — 数据标准化**
- 1m → 因子所需列 (o/h/lo/c/v)；处理午休断层（会话感知重采样）。
- warmup：前 N 根（ATR 14 / MACD 26 / 趋势 20）作预热，不产信号。
- 无前视：成交取**次根开盘**（防前视，Q8 已定）。

**Phase 3 — 因子归因**（利用信号自带 `factors` 字段）
- 全量跑 `detect_miji_signals`（v9.1.0 底座）→ 收集每信号 `factors={'gravity':±1,'vol_div':±1,'macd_div':±1}`。
- 统计：B/S 中各因子触发频率、常见组合。
- **前向收益**：每信号后 N 根（6/12/24）收益，按"单因子触发 vs 多因子"分组比较 → 哪个因子存在与否与前向收益最相关。

**Phase 4 — 消融实验**
- wrapper 使 `detect_miji_signals` 可单独关某因子（传 `enable=(grav,vol,macd)` 开关；不改原函数）。
- 配置：全开 / 仅 gravity / 仅 vol_div / 仅 macd_div / 关 gravity / 关 vol / 关 macd。
- 每配置跑完整回测，记录冻结指标（前向收益 skill）。因子重要性 = 移除后指标下降幅度。

**Phase 5 — 阈值敏感性扫描**
- 对 0.8 引力倍数、`VOL_EXPAND/SHRINK_RATIO`、MACD 三参、`RESONANCE_THRESHOLD` 做网格/单因子扫描。
- 记录指标随参数变化 → 识别"灵敏参数" vs "鲁棒参数"。

**Phase 6 — 汇总与结论**
- 综合归因 + 消融 + 阈值扫描，给出：① 三因子重要性排序；② 各因子最优/鲁棒阈值区间；③ v9.1.0 核心改进建议；④ 是否支撑回到 main 后的改进方向；⑤ 最同步指数结论。
