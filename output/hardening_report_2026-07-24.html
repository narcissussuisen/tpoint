设计原则

  • 不触碰信号算法：所有新增逻辑为「检测 / 通知 / 自修复」外壳，信号判定口径不变 → 守住「复盘忠实」。
  • 自修复仅做数据层：修复动作只是「重连数据源 / 重刷昨收 / 重投补发队列」，不改变任何信号产出 → 守住「送达可靠」。
  • 双通道告警：关键异常同时推信号群(1d241455)与全局任务状态(b4eba7a9)，即使飞书信号群 webhook 自身超时也能通知到。
  • 抗刷屏：所有告警用「连续计数 + 阈值 + 重报间隔」节流，避免每轮刷屏；恢复后发「已恢复」通告。

新增关键函数

  • _alert_global(text) — 经全局 webhook 兜底推送（与信号群互备，不走重试计数，防递归）。
  • _record_push_result(ok) — 每次信号/告警推送成败登记；连续失败达阈值双通道告警，恢复发通告；用 _rec_guard 防递归死循环。
  • push_batch() / _send_alert() — 已接入 _record_push_result，所有用户可见推送均被监测。
  • 扫描循环内：计算异常看门狗 + _tf_unhealthy 自修复 + 静默零信号看门狗。
可调参数（env / config.json 可覆盖，带默认值）：PUSH_FAIL_ALERT_ROUNDS=3、PUSH_FAIL_ALERT_INTERVAL=600s、SILENT_ZERO_ROUNDS=12、SILENT_ZERO_FRESH_S=90、GLOBAL_ALERT_WEBHOOK。
